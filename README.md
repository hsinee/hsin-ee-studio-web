# 芯伊 HSIN.EE 線上預約系統（前台）

客人看到的預約網站，配色與後台營運管理系統一致。
客人選完後，網站會把預約資訊整理好，一鍵帶入官方 LINE 聊天室傳給店家。

網址：https://hsin-ee-booking.vercel.app

## 預約流程

1. 首頁：店家自介、預約須知、「點選開始預約即表示同意本店規範」
2. 基本資料：姓名、手機、預約身分（第一次／6 週內回訪／超過 6 週，不顯示價格名稱）
3. 選擇項目：依身分顯示首次體驗價／回訪價／原價
   分類導覽列：小部位／上半身／下半身／組合優惠／加購優惠／保養產品
4. 預約時間：月曆選日期（公休日無法點選）、希望時段
5. 確認預約內容
6. 匯款訂金提醒 →「傳送到官方 LINE」（自動帶入預約資訊，客人補上匯款末五碼送出）

## 店家後台

網址：https://hsin-ee-booking.vercel.app/admin

打開就能直接修改（不需要密碼），按「儲存並發布」後預約頁面立即更新：

| 區塊 | 可以改什麼 |
| --- | --- |
| 店家資訊 | 店名、標語、自介、營業時間、地址 |
| 預約須知 | 新增、修改、排序、刪除每一條 |
| 項目與價格 | 分類（新增／改名／排序）、項目（新增／改價／排序／暫停／刪除／移到其他分類）、三種價格或固定價格 |
| 價格規則 | 回訪價期限（天數）、三種價格的名稱 |
| 訂金與 LINE | 訂金金額、匯款期限、銀行帳號、戶名、官方 LINE ID |
| 時段與公休 | 公休日（月曆點選）、每週固定公休、開放預約天數、新增／刪除時段 |

- 後台沒有密碼，知道網址的人都能修改，請不要公開 `/admin` 網址（已設定不被搜尋引擎收錄）
- 設定存在 Vercel Blob（`settings.json`），由 `api/settings.js` 讀寫
- `src/config.js` 只是預設內容，後台還沒儲存過設定時才會使用

## 本機開發

```bash
npm install
npm run dev
```

本機 `npm run dev` 沒有 `/api`，預約頁會使用 `src/config.js` 的預設內容；後台的儲存需要部署到 Vercel 才能使用。
